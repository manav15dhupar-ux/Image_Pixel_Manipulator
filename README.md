# 🎨 Image Pixel Manipulator

**Every image is made of pixels. Let's play with them!** 🟦

A Python project where I explore how images work by manipulating their pixels using **NumPy and Matplotlib**.

I developed an image manipulation toolkit using **3D NumPy array slicing, dtype casting (`uint8`/`float32`), and boolean masks** to perform cropping, flipping, channel extraction, and brightness control.

## ✨ What I Learned

- 🖼️ Creating and manipulating images using NumPy arrays
- 🎨 Working with RGB color channels
- 🔴 Extracting individual color channels
- ✂️ Cropping and flipping images using array slicing
- ☀️ Adjusting brightness and working with pixel values
- 🧩 Understanding `uint8`, `float32`, and boolean masks
- 📊 Visualizing images using Matplotlib

## 🛠️ Built With

- **Python** — Core programming
- **NumPy** — Pixel manipulation and array operations
- **Matplotlib** — Image visualization
