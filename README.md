# 🖼️ NumPy Image Processing

Developed an image manipulation toolkit using 3D NumPy array slicing, dtype casting (uint8/float32) and boolean masks for cropping, flipping, channel extraction and brightness control.


### 🚀 What I Learned
- Creating RGB images using NumPy.
- Extracting Red, Green, and Blue channels.
- Displaying channels in grayscale.
- Finding bright pixels using Boolean masks.
- Understanding pixel values and image arrays.

### 🛠️ Tech Stack
`Python` · `NumPy` · `Matplotlib` · `Google Colab`

### 🎯 Goal
Learning image processing step by step through practical coding and experimentation.
